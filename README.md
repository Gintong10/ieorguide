# Infernal Eclipse of Ragnarok: Class Progression Guide

Stage-by-stage gear for all seven classes (Melee, Ranged, Magic, Summoner, Rogue, Healer, Bard) in the
[Infernal Eclipse of Ragnarok](https://terrariamods.wiki.gg/wiki/Infernal_Eclipse_of_Ragnarok) Terraria modpack.

**Read it here: https://gintong10.github.io/ieorguide/**

## How it is built

- `content/` holds one Markdown file per page.
- `python3 build.py` turns them into the static site in `docs/`, which GitHub Pages serves. No dependencies beyond Python 3.

## Where the lists come from

- The modpack's own wiki class setups, where it has written them (all classes before Hardmode, Melee throughout).
- The mods' installed files, read on 7 October 2026: item definitions, recipes and drop tables, with the pack's
  balance changes applied. Placements are computed, not playtested; items marked ≈ were placed by rarity alone.
- The [Calamity Mod wiki](https://calamitymod.wiki.gg/wiki/Guide:Class_setups) class setups for curated Ranged, Magic,
  Summoner and Rogue picks, and the [Thorium Mod wiki](https://thoriummod.wiki.gg/wiki/Guide:Class_setups).

This is an unofficial fan guide. Terraria and every mod named here belong to their creators.
